# Schedule 提醒

在对话里请模型创建、列出、查看、修改、暂停、恢复或删除提醒。每条提醒按自己的规则重复，到点后把指令作为一条自动消息投进一个会话，回答留在那个会话里，可以接着问。

侧栏的「自动化任务」列出这台机器上的提醒，也可以在那里创建、修改、立即执行、暂停、恢复和删除。调度器默认关着。页面上的开关、CLI 的 `/cron daemon on` 和 `~/.agentica/config.yaml` 里的 `settings.cron.enabled` 是同一个开关。应用或网关没在运行时，到期的任务不会投递。

命令行的完整开关、独立 daemon 和排错见 [定时任务](../guides/cron_scheduler.md)。

## 创建提醒

先配好模型。然后直接说，例如：「每天 23:00 提醒我看天气。」模型用 `cronjob` 创建任务。写进任务里的指令要在到点时自己说得通，因为那时没有人在旁边补充。

不经过模型时，打开「自动化任务」，选新建。要填的是名称、内容、执行位置、工作目录和运行时间。新建任务默认是「仅一次」，时间是一小时后，执行位置是「首次新建后沿用」。

执行位置有三种：

| 位置 | 到点之后 |
|---|---|
| 当前会话 | 每次都投进这一个已经存在的会话，能看到之前的对话。适合「在这里提醒我」。 |
| 首次新建后沿用 | 第一次运行新建一个以任务名命名的会话，以后都用它。页面新建任务的默认值。 |
| 每次新建 | 每次运行都开一个新会话，各次之间不接着上次的上下文。 |

## 查看、运行和删除

让模型列出提醒，或打开「自动化任务」。可以按名称或内容搜索，并用「全部 / 已开启 / 已暂停 / 已结束」过滤。每行能看到下次计划时间。

打开一条任务可以看到规则和运行记录。运行记录按时间从新到旧，点一条就去它当时所在的会话。「立即执行」现在就投递一次，不改下次计划时间。会话正忙时会等它空闲再跑，同一条任务不会同时跑两次。

「暂停」之后不再安排投递，「恢复」重新开始。删除会停掉以后的投递，并把这条任务和它保存的运行记录从列表里去掉。已经进入会话的消息还在，对话本身也不会被删。

一次性任务投递之后结束。重复任务在它的规则还有下一次时保持开启。

## 修改任务

在对话里请模型改名称、指令、重复规则或执行位置，也可以在任务详情里改。详情里的修改先留在页面上，选保存才写入。任务的 id 和已经保存的运行记录都保留。

时间可以选：

- **仅一次**：指定日期和时间，跑完就结束。
- **每 N 分钟、每 N 小时**：间隔至少为 1。
- **每天、工作日、每周、每月**：选时间；每周再选星期，每月再选日期。
- **自定义**：填写 cron 表达式。页面认不出的已有规则会以自定义打开，原文保留到你保存一条新规则。

时区用你保存时所在的时区。自定义表达式按它自己写的时区解释。

## 关掉之后再打开

到期时如果调度器没在跑，这次不会投递。重新打开并且调度器开着之后，已经过点的任务会补投一次，然后按规则算下一次。间隔任务不会把关掉期间错过的每一次都补上。

会话忙的时候，到期的消息排队，等这轮结束再进入。投进会话只表示消息已经交给这个对话，不表示模型已经做完。
